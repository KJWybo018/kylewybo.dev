About Me

I’m a software engineer specializing in embedded systems, real‑time software, and systems programming. My experience includes developing embedded C and Python software for GPS clock synchronization and vehicle‑to‑infrastructure (V2X) communication systems, improving timing accuracy by 20% through iterative analysis and refinement.

I’ve configured embedded Linux environments using Buildroot, administered Linux services and daemons, and debugged socket‑level networking issues across distributed hardware nodes. My work spans the full software development lifecycle — requirements, design, implementation, integration, and testing — in collaborative Agile teams.

I’m passionate about building reliable, mission‑driven systems with real‑world impact, whether that’s embedded firmware, simulation tools, or modular software architectures.
